Dogany 개인정보 처리방침

시행일: 2026-10-01

Dogany는 아이폰의 건강 데이터, 문자 내용, 이벤트를 사용자 본인의 맥으로 보내는 앱입니다. 개발자는 이 데이터를 받지 않고, 수집하지 않습니다.

다루는 데이터

  • 건강 데이터: 사용자가 허용한 HealthKit 종류(운동, 수면, 걸음, 심박 등)
  • 문자 내용: 사용자가 단축어 앱에서 직접 만든 자동화가 보내도록 한 문자
  • 이벤트: 사용자가 설정한 알림이나 단축어 동작이 만든 기록

데이터가 가는 곳

위 데이터는 사용자 본인의 맥에서 돌아가는 receiver 프로그램으로만 갑니다. 전송은 사용자의 Tailscale 네트워크 안에서 이루어집니다. 개발자의 서버, 클라우드 저장소, 분석 도구, 광고 서비스, 제3자는 이 경로에 없습니다.

개발자가 수집하는 것

없습니다. 개발자는 사용자의 건강 데이터, 문자 내용, 이벤트, 기기 식별자, 사용 기록을 받거나 저장하지 않습니다. 건강 데이터를 광고나 마케팅에 쓰거나 제3자에게 제공하지 않습니다.

보관과 삭제

전송된 데이터는 사용자의 맥 안에만 저장됩니다. 보관 기간과 삭제는 사용자가 맥에서 직접 정합니다. 앱을 지우면 아이폰에서의 전송이 멈춥니다. HealthKit 접근 권한은 아이폰의 설정, 건강 앱에서 언제든 끌 수 있습니다.
