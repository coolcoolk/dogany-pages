Dogany 설치

맥과 아이폰에 Dogany를 설치하고 연결합니다.

필요한 것

도가니맥미니에서 쓰고 있는 도가니
Tailscale맥과 아이폰에 설치하고 같은 계정으로 로그인합니다. Tailscale 내려받기

순서

  1. 맥에 Dogany 설치

    내려받은 파일을 열고 Dogany를 응용 프로그램 폴더로 옮깁니다.

    Dogany.dmg 내려받기
  2. 맥에서 Dogany 열기

    처음 설정이 Tailscale과 HTTPS 인증서를 확인합니다. 화면의 안내를 따릅니다. HTTPS 인증서는 Tailscale 관리 콘솔에서 켭니다. HTTPS 켜는 방법

  3. 아이폰에 Dogany 설치

    초대 메일의 링크로 TestFlight를 열고 Dogany를 설치합니다. TestFlight가 없으면 먼저 설치합니다. TestFlight 받기

  4. 아이폰과 맥 연결

    맥의 Dogany에서 상태 > 아이폰 연결하기를 눌러 QR을 표시합니다. 아이폰의 Dogany에서 QR로 페어링을 누르고 QR을 찍습니다.

처음 열 때

확인 창 한 번Dogany는 Apple 공증을 받은 앱입니다. 처음 열면 인터넷에서 내려받은 앱이라는 확인 창이 한 번 나오고, 열기를 누르면 됩니다. Apple 안내

업데이트

새 버전 받기Dogany를 종료하고 위의 Dogany.dmg를 다시 내려받습니다. 파일을 열어 Dogany를 응용 프로그램 폴더로 옮기고 기존 앱을 교체합니다.

Tailscale, TestFlight, 확인 창의 설명은 각 공식 문서를 기준으로 적었고, 기기에서 직접 확인한 내용이 아닙니다.
